## 从公开仓库重新部署

在同一台 Windows 11 参考机上，从固定提交重新获取源码，在全新的 Python 虚拟环境里逐例运行。独立复现与参考运行的 693 个可达性结论逐例一致。复现路径长度相对于参考运行有 622 条等长、3 条更短、2 条更长。程序内求解累计 215.77 秒，逐例 CLI 耗时累计 312.43 秒，下载另计。
